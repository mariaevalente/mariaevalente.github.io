A small language for expert control rules, with its own parser, compiler and interpreter.

Role
Designer and developer
Delivered

Years
2023–2024
Stack
Python, PLY

Why a language

Expert control rules were written in code, one building at a time, which made them hard to review and easy to break. A language of their own would let engineers write rules close to how they think about a building, with the parser rejecting a malformed rule before it reached a controller.

2,600lines of Python for the compiler and interpreter
4test suites, unit and functional, for both halves

What I built

  • The grammar, and a lexer and parser on PLY.
  • The syntax tree and its compilation to a JSON program designed for the rule engine to store and run.
  • The interpreter, including how undefined values, type coercion and command priorities behave.
  • The documentation: grammar, semantics, JSON schema and a tutorial for engineers.
